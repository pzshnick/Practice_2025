Title: Project Creation

The project originally named "Car Parking" has been renamed to "for review and learning", as it is a demonstration project containing a test version of a mini-game. The main gameplay revolves around parking cars and earning points. In parallel, a basic UI has been designed, including core game control elements and a store page. The project uses semantic names, simple scenes, and minimal controllers aimed at initial exploration of the game engine.

A new project titled "Battle of Machines" has been created, which will serve as the main project during the practical training. It is a mini-strategy game where the main actors are machines (initially cars). The core of the project will first be implemented by me, after which it is planned to expand the game logic and scale up the functionality as long as the team is able to continue working on it.

The final result should be a completed mini-game, properly tested in advance and ready for real demonstration to our supervisor.

Wishing both you and myself good luck!
